# Tiller Codex Operating Notes

<!-- BEGIN TILLER CODEX OPERATING NOTES -->
When Tiller ambient mode is active, read [the operating contract](docs/agent-workflows/tiller.md) once and follow its execution boundaries, task descriptors, and lifecycle rules. Read compact run status before raw logs. Do not retry denied root execution through another command.

When ambient mode is inactive, ordinary work needs no Tiller orchestration or delegation. Use the tools available in the current session and preserve required repository checks. Reuse current evidence and keep output scoped.
